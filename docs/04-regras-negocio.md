# Cancelamento

Planejado = Sim
Executado = Não

Resultado:

Cancelado


# Encaixe

Planejado = Não
Executado = Sim

Resultado:

Encaixe


# Transferido

Entregador Planejado
≠
Entregador Executado


# Recebido

Entrega planejada para outro entregador
e executada pelo entregador atual.


# Executadas

Executadas =
Planejadas
- Canceladas
- Transferidas
+ Recebidas
+ Encaixes
