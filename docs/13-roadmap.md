# Roadmap do Projeto

## Objetivo

Definir as fases de desenvolvimento da Plataforma Operacional Coco Legal.

---

# Fase 1 - Fundação

Status:

Em desenvolvimento

Objetivos:

- Estruturar GitHub
- Estruturar documentação
- Estruturar Supabase
- Modelar banco de dados
- Criar ERD

Entregas:

- Cadastros
- Importações
- Estrutura de usuários
- Modelo de dados

- Planejados
- Executados

Primeira versão operacional funcional.
